# 🤖 AI三级发布系统

## 📋 系统概述

这是一个智能化的三级发布系统，通过简单的指令即可完成不同程度的代码发布：

- **q3**: 快速代码保存（仅版本递增，不发布）
- **q1**: 半自动化PR流程（创建PR等人工合并）  
- **q2**: 完整自动化发布（直接发布到市场）

## 🎯 使用方法

在GitHub Issue或Discussion中发送以下指令：

```
发布q3    → 快速保存当前代码版本
发布q1    → 创建PR等待人工合并审查
发布q2    → 完整自动化发布到市场
```

## ⚙️ 系统特点

### 🔧 智能化处理
- 自动版本号管理
- 智能提交类型识别
- 多平台自动构建
- 一键触达完整流程

### 🛡️ 安全控制
- 主分支保护机制
- 人工审查环节可选
- 完善的错误处理
- 详细的操作日志

### 🚀 高效便捷
- 零代码操作
- 零命令行使用
- 三步完成发布
- 状态实时反馈

## 📊 流程说明

### q3快速保存流程
```
用户指令 → 版本递增 → 代码提交 → 完成
```

### q1半自动化流程  
```
用户指令 → 创建分支 → 提交代码 → 创建PR → 等待合并 → 自动触发q2
```

### q2完整发布流程
```
用户指令/PR合并 → 版本分析 → 多平台构建 → GitHub Release → 市场发布 → 完成
```
