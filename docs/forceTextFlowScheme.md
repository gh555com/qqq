# 两种 HTML 粘贴方案深度对比

## 核心原理差异

### 方案一 (`handleClipboardNode`) - "跳出范式"

```
HTML DOM 结构  ──┬──▶  提取图片位置标记
                │
剪切板纯文本   ──┴──▶  流式消费 cleanText，用 HTML 结构定位图片插入点
```

**核心思想**：用 **纯文本内容** 替代 HTML 文本（避免乱码），用 **HTML 结构** 仅定位图片位置

```javascript
// 方案一的关键逻辑
const cleanText = await vscode.env.clipboard.readText(); // 获取纯文本
let textCursor = 0; // 流式消费指针

for (const node of flatNodes) {
    if (node.type === 'media') {
        blocks.push(node); // 图片直接插入
    } else if (node.type === 'text') {
        // 用 HTML 文本片段作为"锚点"，在 cleanText 中查找匹配位置
        const startAnchorObj = getSmartAnchor(trimmedHtml, 0, 10);
        let idx = searchArea.indexOf(startAnchorObj.text);
        // ... 消费 cleanText 对应片段
    }
}
```

### 方案二 (`handleClipboardNodeScheme2`) - "原范式"

```
CF_HTML 原始字节 ──▶ 智能编码检测 ──▶ 解码 ──▶ DOM 遍历 ──▶ 按序打印
```

**核心思想**：直接从 HTML 提取一切，完整保留 DOM 顺序

```javascript
// 方案二的关键逻辑
const sliced = _sliceCfHtmlPayload(rawBuf);     // 按 CF_HTML 字节偏移切片
htmlText = _decodeHtmlBytesSmart(payload);       // 智能编码检测(UTF-8/UTF-16/Latin1)
htmlText = _repairBrokenAngleTags(htmlText);     // 修复 "?/span>" 等乱码标签

// DOM 遍历，按顺序打印
function walk(node) {
    if (node.type === "text") {
        textBuf += node.data;  // 直接用 HTML 文本
    } else if (tag === "img") {
        blocks.push({ type: "media", ... });
    }
}
```

## 多维度量化打分

| 维度         | 方案一 (跳出范式) | 方案二 (原范式) | 权重  |
| ---------- | ---------- | --------- | --- |
| **乱码抗性**   | ⭐⭐⭐⭐⭐ (5)  | ⭐⭐⭐ (3)   | 25% |
| **图文位置精度** | ⭐⭐⭐ (3)    | ⭐⭐⭐⭐⭐ (5) | 25% |
| **代码复杂度**  | ⭐⭐ (2)     | ⭐⭐⭐ (3)   | 15% |
| **边界情况覆盖** | ⭐⭐⭐ (3)    | ⭐⭐⭐⭐ (4)  | 20% |
| **性能**     | ⭐⭐⭐⭐ (4)   | ⭐⭐⭐ (3)   | 15% |

**加权得分**：

* 方案一：5×0.25 + 3×0.25 + 2×0.15 + 3×0.20 + 4×0.15 = **3.40**
* 方案二：3×0.25 + 5×0.25 + 3×0.15 + 4×0.20 + 3×0.15 = **3.70**

## 失败场景对比

```
┌─────────────────────────────────────────────────────────────────┐
│                        方案一会失败                              │
├─────────────────────────────────────────────────────────────────┤
│ 1. 纯文本与 HTML 文本差异过大                                    │
│    HTML: "• 项目1"  vs  纯文本: "- 项目1"                        │
│    → 锚点匹配失败，图片位置漂移                                  │
│                                                                 │
│ 2. 复杂表格/嵌套结构                                            │
│    HTML DOM 顺序 ≠ 纯文本阅读顺序                                │
│    → 流式消费乱序                                               │
│                                                                 │
│ 3. 纯文本被浏览器/系统"清洗"过                                   │
│    → 长度对不上，cursor 漂移                                    │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                        方案二会失败                              │
├─────────────────────────────────────────────────────────────────┤
│ 1. CF_HTML 编码检测失败                                         │
│    某些应用打印非标准编码（如 GB2312 混合）                      │
│    → 中文变成 ??? 或 \uFFFD                                     │
│                                                                 │
│ 2. HTML 严重畸形                                                │
│    未闭合标签、嵌套错误                                          │
│    → cheerio 解析崩溃或丢内容                                   │
│                                                                 │
│ 3. 特殊字符实体未解码                                           │
│    &amp;nbsp; 残留、&#x 编码                                    │
│    → 文本显示异常                                               │
└─────────────────────────────────────────────────────────────────┘
```
