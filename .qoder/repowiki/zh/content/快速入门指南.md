## 环境准备

在开始使用 QQQ 扩展之前，请确保您的开发环境已正确配置。本扩展依赖以下运行时和工具：

- **Node.js**：版本 >= 14
- **VSCode**：版本 >= 1.70.0
- **Python 3.x**：用于处理剪贴板中的图片和文件操作

您可以通过以下命令验证环境是否就绪：

```bash
node --version
code --version
python --version
```

如果任一命令未返回预期版本号，请先安装或升级相应组件。

## 安装扩展

您可以选择以下任一方式安装 QQQ 扩展：

### 方式一：通过 VSIX 文件安装

1. 下载 `qqq-1.0.0.vsix` 文件。
2. 在终端中执行以下命令进行安装：
   ```bash
   code --install-extension qqq-1.0.0.vsix
   ```

### 方式二：通过 VSCode 市场搜索安装

1. 打开 VSCode。
2. 进入“扩展”面板（快捷键 `Ctrl+Shift+X`）。
3. 搜索关键词 **"qqq"**。
4. 找到 QQQ 扩展后点击“安装”。

安装完成后，无需重启 VSCode，扩展将自动激活。

## 使用 Q1 智能粘贴功能

Q1 功能提供增强的粘贴体验，支持自动转换剪贴板中的图片、文件路径等，并在编辑器中预览图片。

### 操作步骤

1. 复制一张图片或文件路径到系统剪贴板。
2. 在 VSCode 编辑器中，按下以下快捷键：
   - Windows/Linux：`Ctrl+V`
   - macOS：`Cmd+V`
3. 或者，通过命令面板运行命令：
   - 按 `Ctrl+Shift+P` 打开命令面板。
   - 输入并选择 **"QQQ: Q1"**。

执行后，系统会将内容保存至 `D:\view\p\` 目录，并在编辑器中插入 `[D:\view\p\xxx.png]` 格式的路径。若为图片，将在下方以 512x288 尺寸预览。

## 使用 Q2 文件导航功能

Q2 提供强大的可视化文件导航功能，支持快速创建文件、浏览目录、管理历史记录等。

### 操作步骤

1. 在 VSCode 编辑器中，按下快捷键 `F2`。
2. 或者，通过命令面板运行命令：
   - 按 `Ctrl+Shift+P` 打开命令面板。
   - 输入并选择 **"QQQ: 新建文件..."**。

打开后，您将看到如下界面功能：

- **左侧导航栏**：显示驱动器列表（如 C:\, D:\）。
- **最近访问目录**：顶部列出最近打开的 10 个目录，可点击快速跳转。
- **文件列表**：右侧显示当前目录下的文件和文件夹，支持点击进入。
- **底部操作区**：
  - 输入文件名后按回车即可创建新文件。
  - 点击“长驻”按钮可保持窗口打开，连续创建多个文件。

### 键盘快捷键（在 Q2 对话框中）

| 快捷键 | 功能 |
|--------|------|
| `q` | 重命名选中项 |
| `w` | 用默认应用打开 |
| `s` | 删除到回收站 |
| `e` | 在 VSCode 中打开 |
| `Backspace` | 返回上级目录 |

## 调试与开发

如果您希望参与扩展开发或调试其行为，请按以下步骤操作：

1. 在 VSCode 中打开本项目根目录。
2. 按下 `F5` 启动扩展开发主机。
3. 一个新的 VSCode 实例将启动，其中已加载当前扩展。
4. 在该实例中测试 Q1 和 Q2 功能，观察控制台输出日志。

日志文件路径为 `D:\view\p\kp.log`，可用于排查 Python 脚本执行问题。

## 常见问题

### 命令未找到？

如果运行命令时报错“命令未找到”，请检查以下几点：

1. 确认扩展已成功安装且未禁用。
2. 检查 `package.json` 中的 `contributes.commands` 是否包含对应命令。
3. 重启 VSCode 或重新加载窗口（`Ctrl+R`）。

相关诊断文档可参考：[命令未找到诊断.md](file://命令未找到诊断.md)

### 图片预览不显示？

- 确保图片已成功粘贴并保存至 `D:\view\p\`。
- 检查 `sharp` 库是否安装成功（依赖项之一）。
- 查看日志文件 `D:\view\p\kp.log` 是否有错误信息。

### 如何修改配置？

扩展使用独立配置文件 `E:\r\pz.ini`，支持以下设置：

- `recent_dirs`：最近访问的目录
- `sidebar_width`：侧边栏宽度
- `size_mode`：文件大小显示模式（none/m/k/b）

修改后需重启 VSCode 生效。
