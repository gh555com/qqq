## 函数功能概述

`generateWebviewScript()` 函数负责生成完整的前端 JavaScript 代码字符串，该字符串包含 Webview 所需的所有交互逻辑。生成的脚本涵盖了 DOM 事件监听器、消息通信处理、焦点管理、文件操作等多个功能模块。此函数通过模板字符串返回一个完整的 JavaScript 代码块，该代码块在 Webview 加载时执行，为用户提供完整的文件管理界面交互能力。

## 参数注入机制

`generateWebviewScript()` 函数接收 `currentSizeMode` 和 `currentPath` 两个参数，并将其嵌入生成的脚本中。`currentSizeMode` 参数用于设置文件大小显示模式，`currentPath` 参数用于设置当前路径。这两个参数通过模板字符串的方式嵌入到生成的 JavaScript 代码中，确保 Webview 在加载时能够获取到正确的配置信息。`currentPath` 参数在嵌入前会进行路径转义处理，以确保在 JavaScript 中正确解析。

## 占位符与代码注入点

`{{INLINE_SCRIPT}}` 占位符位于 `q2.html` 文件的 `<script>` 标签内，作为代码注入点。当 Webview 内容生成时，`generateWebviewScript()` 函数生成的 JavaScript 代码会替换 `{{INLINE_SCRIPT}}` 占位符，从而将完整的前端逻辑注入到 HTML 页面中。这一机制确保了 HTML 模板与 JavaScript 逻辑的分离，同时允许动态生成和注入代码，提高了代码的可维护性和灵活性。

## VSCode API双向通信

脚本注入后，通过 `acquireVsCodeApi()` 获取 VSCode API，实现与 Webview 的双向通信。Webview 通过 `postMessage` 方法发送 `navigate`、`save`、`togglePin` 等命令，与 VSCode 扩展进行交互。同时，Webview 监听 `message` 事件，处理来自 VSCode 的 `update`、`updateSize` 等响应。这种双向通信机制使得 Webview 能够实时更新界面状态，响应用户操作，并与 VSCode 的文件系统进行同步。
