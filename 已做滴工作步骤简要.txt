## 问题修复记录

[2025-10-15] **修复界面空白问题**

问题描述：
- 界面完全空白（黄色背景）
- 历史区不显示
- 文件列表不显示
- 侧边栏拖动失效

根本原因：
- src/q2.js 中配置分隔符使用了分号(;)
- extension.js 原始代码使用的是逗号(,)
- 导致配置读取失败，数组为空

修复方案：
- 修改 src/q2.js 第 197 行：.split(",")  // recent_dirs
- 修改 src/q2.js 第 234 行：.split(",")  // recycle_bin
- 修改 src/q2.js 第 283-287 行：.join(",")  // 保存配置

[2025-10-15] **紧急修复界面乱码问题**

致命错误 1：缺少 vscode 模块导入
- 位置：src/q2.js 第 1 行
- 修复：添加 const vscode = require("vscode");
- 影响：所有 vscode API 调用失败，扩展崩溃

致命错误 2：HTML 占位符被破坏
- 位置：src/q2.html 多处
- 问题：{{ SIDEBAR_WIDTH }} 被格式化为 { { SIDEBAR_WIDTH } }
- 修复：删除并重新创建 q2.html
- 验证：verify-placeholders.js 测试通过 ✅
- 影响：CSS 无法解析，界面完全混乱
