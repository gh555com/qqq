# QQQ VSCode 扩展

一个功能强大的 VSCode 扩展，提供智能文件操作、图片预览和文件导航功能。

---

## ✨ 主要功能

### 🎨 Q1 - 智能粘贴与图片预览
- **智能粘贴**：增强的粘贴功能，支持文件路径自动转换
- **图片预览**：在编辑器中直接预览图片，支持自动缩放（512x288）
- **CodeLens**：为图片路径提供快速打开功能
- **块模式切换**：灵活的图片显示模式

### 📂 Q2 - 强大的文件导航
- **可视化文件浏览**：直观的文件和文件夹导航界面
- **快速新建**：一键创建文件和文件夹
- **智能历史**：记录最近访问的10个目录
- **历史回收站**：安全保存移除的历史记录（最多60条）
- **右键菜单**：支持重命名、删除、打开等操作
- **键盘快捷键**：
  - `q` - 重命名
  - `w` - 用默认应用打开
  - `s` - 删除到回收站
  - `e` - 在 VS Code 中打开
  - `Backspace` - 返回上级目录
- **文件大小显示**：支持 none/m/k/b 四种模式
- **可拖动侧边栏**：自定义导航栏宽度
- **长驻模式**：保持对话框打开，连续创建文件

## 🚀 快速开始

### 安装
```bash
# 从 VSIX 安装
code --install-extension qqq-1.0.0.vsix

# 或在扩展市场搜索 "qqq"
```

### 使用

#### Q1 - 粘贴功能
1. 在编辑器中按 `Ctrl+V` (Windows/Linux) 或 `Cmd+V` (macOS)
2. 或运行命令：`QQQ: Q1`

#### Q2 - 文件导航
1. 按 `F2` 打开文件导航对话框
2. 或运行命令：`QQQ: 新建文件...`

## ⚙️ 配置

### VS Code 设置

```json
{
  "qqq.showHistoryRecycleBin": true  // 是否显示历史回收站
}
```

### 配置文件位置

扩展使用独立配置文件：`E:\r\pz.ini`

配置项包括：
- `recent_dirs` - 最近访问的目录
- `line_spacing` - 列表项间距
- `sidebar_width` - 侧边栏宽度
- `recycle_bin` - 历史回收站内容
- `is_pinned` - 长驻模式状态
- `size_mode` - 文件大小显示模式

## 📝 架构说明

### 模块化设计

扩展采用清晰的模块化架构：

1. **qqq.js** - 核心模块
   - 提供公共配置和工具函数
   - 管理模块激活和生命周期
   - 导出共享资源

2. **q1.js** - 文件操作模块
   - 处理粘贴和图片相关功能
   - 管理 CodeLens 和装饰
   - 与 kp.py 脚本交互

3. **q2.js** - 文件导航模块
   - 管理 Webview 对话框
   - 处理文件系统操作
   - 配置文件读写

4. **q2.html** - UI 模板
   - 纯 HTML/CSS 模板
   - 使用占位符系统
   - 无内联脚本或样式

### HTML/JS 分离策略

**问题**：避免在 JS 中内嵌大量 HTML 字符串

**解决方案**：
```javascript
// q2.html - 独立的 HTML 模板
<div class="sidebar" style="width: {{SIDEBAR_WIDTH}}px">
  {{DRIVES_HTML}}
</div>

// q2.js - 读取并替换占位符
const template = fs.readFileSync('q2.html', 'utf8');
const html = template.replace(/{{SIDEBAR_WIDTH}}/g, sidebarWidth);
```

**优势**：
- ✅ 职责分离清晰
- ✅ HTML 易于维护
- ✅ JS 代码更简洁
- ✅ 支持语法高亮

## 🐛 已知问题

1. **图片预览**：仅支持 `D:\view\p\` 路径下的图片
2. **删除功能**：依赖系统回收站工具
   - Windows: 内置支持
   - macOS: 需要 `trash` 命令
   - Linux: 需要 `gvfs-trash` 命令
